# Ejercicio 8 — Q-learning

Desde esta carpeta ejecuta:

```bash
python3 main.py
```

No requiere instalar paquetes. Muestra la política y el camino en la terminal.
Con semilla 1 obtiene 13 pasos y retorno −13.
Para cambiar el número de episodios: `python3 main.py --episodios 1000`.
También acepta `--episodes`, como el proyecto original.
Sin argumentos usa 500 episodios, que es la corrida solicitada para la entrega.
Cada corrida reemplaza `recompensas.csv` con los episodios nuevos.
El reporte está en `reporte.md`.
